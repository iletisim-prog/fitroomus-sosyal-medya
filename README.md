# fitroomus — sosyal medya görselleri

fitroomus.com için Instagram/Facebook gönderi (1080×1350) ve hikâye (1080×1920) görselleri.

- `g/` — tüm görseller (`f-*` gönderi, `s-*` hikâye)
- `metricool-30gun.csv` — Metricool toplu yükleme dosyası (3 Ekim – 1 Kasım 2026, günde 4 gönderi + 6 hikâye)
- `takvim-30gun.txt` — tarih / saat / görsel listesi
